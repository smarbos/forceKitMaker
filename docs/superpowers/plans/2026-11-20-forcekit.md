# forcekit Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A local tool that indexes `~/Samples/samples`, lets you browse and audition it in a web page, assemble drum kits (pads) and synths (keygroups), and export them as Akai Force 3.10 programs.

**Architecture:** One Python package. `scan` walks the library into `index.json`; `serve` runs a stdlib threaded HTTP server exposing a small JSON API plus a static vanilla-JS page; `export` turns a draft (JSON) into an `.xpm` + `_[ProgramData]` folder by modifying copies of Damian's own Force templates.

**Tech Stack:** Python 3.14, numpy, soundfile, pytest; ffmpeg (fallback decoder); plain HTML/CSS/JS (no build step).

**Spec:** `docs/superpowers/specs/2026-11-20-forcekit-design.md`

## Global Constraints

- Never write to, move, or delete anything under the library root (`~/Samples/samples`).
- Server binds `127.0.0.1` only, default port `8765`.
- Defaults: library `~/Samples/samples`; data dir `~/Samples/forcekit/` (`index.json`, `drafts/`, `cache/`); export dir `~/Samples/force-out/`; config file `~/.config/forcekit/config.json` (optional, overrides defaults).
- Audio extensions indexed: `.wav .aif .aiff .mp3`, case-insensitive. Skip `__MACOSX` dirs, names starting with `._` or `.`, and the data/export dirs.
- Note naming: MIDI 60 = `C3` (Akai convention). Default synth root when unknown: 60.
- Drum programs: 64 pads (banks A–D × 16), one sample per pad, pad index `p` (0-based) → `drum.instruments[p]`.
- Synth programs: max 128 samples, unique root notes, key ranges by midpoint rule.
- `.xpm` = gzip( header `ACVS\n3.10.1.12\nSerialisableProgramData\njson\nLinux\n` + JSON `{"data": {...}}` indented 4 spaces ). Header is taken from the template file, not hard-coded.
- Export layout: `<export>/Drums/<Name>.xpm` or `<export>/Synths/<Name>.xpm`, samples in sibling `<Name>_[ProgramData]/`.
- Normalize on export (default on): drums per-sample peak to −1 dBFS; synth one shared gain so the loudest peak is −1 dBFS. Silent audio (peak 0) gets gain 1.
- Exported WAVs: PCM_24 if the source is 24-bit, 32-bit or float, else PCM_16; source sample rate kept.
- No sample editing anywhere in the UI. The only per-sample setting is a synth sample's root note.
- Deviation from spec, builder's call: pitch detection is a small numpy YIN instead of librosa (librosa pulls numba, which is fragile on Python 3.14).

## Review Focus

1. **Non-ASCII / odd filenames** (`sonidios de dios`, accents, `#`, `&`, brackets): browsing, playback URLs and export must all work. Tests in Tasks 4, 5, 6.
2. **WAVs the browser or Force can't play** (IMA/MS ADPCM, 8-bit, A-law from old packs): playback transcodes them, export converts them to PCM. Tests in Tasks 5, 6.
3. **Two samples with the same filename in one program** (`Kick 01.wav` from two packs): export must give them distinct files. Test in Task 5.
4. **Unreadable / corrupt files:** scan records `error` and continues; playback returns 422, not a crash. Tests in Tasks 3, 6.
5. **Path traversal** (`../`, absolute paths, symlinks out of the library) on any API taking a path: 403. Test in Task 6.

**Interfaces:**
- Produces:
  - `Config(library: Path, data_dir: Path, export_dir: Path, port: int = 8765)` with properties `index_path`, `drafts_dir`, `cache_dir`.
  - `load_config(path: Path | None = None) -> Config` — defaults per Global Constraints; JSON file keys `library`, `data_dir`, `export_dir`, `port` override; `~` expanded.
  - `parse_note(text: str) -> int | None` — returns the MIDI note of the **last** token of a filename stem (tokens split on `[\s_\-.()\[\]]+`) that fully matches `([A-Ga-g])([#b]?)(-?\d)`; MIDI = 12*(octave+2) + pitch class.
  - `note_name(midi: int) -> str` — sharps only.
  - `key_ranges(roots: list[int]) -> list[tuple[int, int]]` — input sorted unique; zone i low = 0 if first else (r[i-1]+r[i])//2 + 1; high = 127 if last else (r[i]+r[i+1])//2.
  - `safe_name(text: str, max_len: int = 48) -> str` — NFKD → ASCII, drop `/\:*?"<>|` and control chars, collapse whitespace, strip; empty → `"untitled"`.
  - `unique_name(name: str, taken: set[str]) -> str` — returns `name`, else `name 2`, `name 3`…; adds result to `taken`.

### Task 2: Audio helpers

**Files:**
- Create: `forcekit/audio.py`, `tests/conftest.py`
- Test: `tests/test_audio.py`

**Interfaces:**
- Produces:
  - `AudioInfo(duration: float, samplerate: int, channels: int, subtype: str, format: str)`
  - `probe(path: Path) -> AudioInfo` — `soundfile.info`; on failure falls back to `ffprobe -v error -show_streams -of json`; raises `AudioError(str)` if both fail.
  - `load(path: Path) -> tuple[np.ndarray, int, str]` — float32 array shape `(frames, channels)`, samplerate, subtype; soundfile first, fallback `ffmpeg -i path -f wav -c:a pcm_f32le -` piped and read with soundfile; `AudioError` on failure.
  - `browser_playable(entry_format: str, subtype: str | None) -> bool` — True for `mp3`, and for `wav` with subtype in `{"PCM_16","PCM_24","PCM_32","FLOAT"}`; False otherwise (AIFF, ADPCM, PCM_U8, ULAW, ALAW…).
  - `export_subtype(subtype: str) -> str` — `"PCM_24"` for `PCM_24`, `PCM_32`, `FLOAT`, `DOUBLE`; else `"PCM_16"`.
  - `write_wav(path: Path, data: np.ndarray, samplerate: int, subtype: str) -> None` — clips to [−1, 1].
  - `peak(data: np.ndarray) -> float`
  - `gain_to(target_peak_db: float, current_peak: float) -> float` — returns 1.0 when `current_peak == 0`.
  - `detect_root(path: Path) -> int | None` — first 1 s, mono mix; YIN with frame 2048, hop 512, f0 range 30–2000 Hz, threshold 0.15; voiced = frames whose CMNDF minimum < threshold; return `round(69 + 12*log2(median_f0/440))` if ≥ 30 % of frames voiced, else None.

### Task 3: Scanner

**Files:**
- Create: `forcekit/scan.py`

**Interfaces:**
- Consumes: `probe`, `AudioError` (Task 2); `parse_note` (Task 1); `Config` (Task 1).
- Produces:
  - `type_hint(rel_path: str) -> str | None` — tokens = split on non-alphanumerics **and** camelCase boundaries, lower-cased; check filename stem tokens first, then folder names from nearest to farthest; first match wins. Table (checked in this order per token list):
    `loop`: loop, bpm · `kick`: kick, kik, bd, bassdrum · `snare`: snare, snr, sd · `clap`: clap, clp, cp · `hat`: hat, hats, hh, hihat, oh, ch · `tom`: tom, toms · `cymbal`: cymbal, cym, cy, crash, ride, china, splash · `perc`: perc, percussion, conga, bongo, shaker, tamb, tambourine, cowbell, rim, rimshot, clave, block · `fx`: fx, sfx, effect, effects, impact, riser, sweep, noise · `vocal`: vox, vocal, voice, speech, spoken · `bass`: bass · `synth`: synth, lead, stab, arp · `pad`: pad, pads, chord, chords, strings.
    (`bass drum` as two tokens → kick: check the bigram `bass drum` before single tokens.)
  - `file_hash(path: Path) -> str` — blake2b (16-byte digest) of `size` + first 1 MiB.
  - `scan_library(cfg: Config, progress: Callable[[int, int], None] | None = None) -> dict` — returns and writes the index (shape above) to `cfg.index_path` atomically (write temp, rename). Reuses previous entries whose `size` and `mtime` are unchanged. `dup_of` = path of the first file (sorted order) with the same hash, else None. Unreadable files keep the entry with `duration/samplerate/channels/subtype = None` and `error` = message. Skips per Global Constraints, plus `cfg.data_dir` and `cfg.export_dir` when inside the library.

**Interfaces:**
- Produces:
  - `read_xpm(path: Path) -> tuple[bytes, dict]` — gunzip; header = bytes up to the first `{`; JSON parsed from the rest.
  - `write_xpm(path: Path, header: bytes, doc: dict) -> None` — `gzip(header + json.dumps(doc, indent=4, ensure_ascii=False).encode("utf-8"))`.

Loads `keygroup.xpm`; `data.keygroup.numKeygroups = len(zones)`; `data.drum.instruments` = one deep copy of the template's instrument 0 per zone with `lowNote`, `highNote`, and `layersv[0]` `sampleName`, `sampleFile`, `rootNote=root`, `keyTrackEnable=True`, `active=True`; `data.samples[]` entries with `metadata.rootNote=root`.

### Task 5: Drafts and export

**Files:**
- Create: `forcekit/drafts.py`, `forcekit/export.py`
- Test: `tests/test_drafts.py`, `tests/test_export.py`

**Interfaces:**
- Consumes: `Config`, `safe_name`, `unique_name`, `key_ranges` (Task 1); `load`, `write_wav`, `peak`, `gain_to`, `export_subtype`, `browser_playable` (Task 2); `build_drum`, `build_keygroup`, `write_xpm`, `SampleRef` (Task 4).
- Produces:
  - `DraftError(Exception)`.
  - `validate_draft(draft: dict) -> None` — raises `DraftError` for: unknown `type`; drum pad keys outside `"0"`–`"63"`; synth with > 128 samples, duplicate roots, or roots outside 0–127; any path that is absolute or contains `..`.
  - `save_draft(cfg, draft) -> str` (returns the file stem = `safe_name(draft["name"])`), `load_draft(cfg, stem) -> dict`, `list_drafts(cfg) -> list[dict]` (`{"stem","name","type","mtime"}`, newest first), `delete_draft(cfg, stem) -> None`. All validate; stems are `safe_name`d so they can't escape `drafts_dir`.
  - `ExportExists(Exception)` with `.path`.
  - `export_program(cfg: Config, draft: dict, normalize: bool = True, overwrite: bool = False) -> Path` — returns the `.xpm` path. Program name = `safe_name(draft["name"])`. Raises `ExportExists` if the `.xpm` exists and not `overwrite`; with `overwrite`, removes the old `.xpm` and `_[ProgramData]` folder first. Per sample: sample name = `unique_name(safe_name(stem))`, file = name + `.wav`. Writes audio:
    - copy bytes unchanged when `normalize` is False **and** source is a `browser_playable` WAV (that set is also what the Force reads);
    - otherwise `load` → apply gain (drums: `gain_to(-1, peak(sample))`; synth: one `gain_to(-1, max peak)` for all; 1.0 when not normalizing) → `write_wav` with `export_subtype(source subtype)`.
    Synth zones from `key_ranges(sorted roots)`.

### Task 6: HTTP server and API

**Files:**
- Create: `forcekit/server.py`
- Test: `tests/test_server.py`

**Interfaces:**
- Consumes: everything above; reads the index from `cfg.index_path` at start (error message telling the user to run `forcekit scan` if missing).
- Produces: `make_server(cfg: Config, port: int = 0) -> ThreadingHTTPServer` (port 0 = random, for tests) and `serve(cfg) -> None`. API (all JSON unless noted; paths are library-relative POSIX, passed URL-encoded in the `path` query param):

| Method | Route | Result |
|---|---|---|
| GET | `/` and `/static/<file>` | files from `forcekit/web/` |
| GET | `/api/tree` | `{"name","path","count","children":[...]}` — every folder that contains indexed files or has descendants that do; `count` = files directly in it |
| GET | `/api/folder?path=` | `[FileEntry...]` directly in that folder, natural-sorted by filename |
| GET | `/api/audio?path=` | audio bytes. `browser_playable` → file as-is (`audio/wav` / `audio/mpeg`); else load → 16-bit WAV cached at `cache_dir/<hash>.wav`. 422 `{"error"}` if undecodable |
| GET | `/api/root?path=` | `{"root": int, "source": "filename"|"detected"|"default"}` (index `note` → `detect_root` → 60) |
| GET | `/api/drafts` · `/api/drafts/<stem>` | list · one draft |
| PUT | `/api/drafts/<stem>` | body = draft; save; returns `{"stem"}` (stem may differ if name changed; client uses the returned one) |
| DELETE | `/api/drafts/<stem>` | 204 |
| POST | `/api/export` | body `{"draft", "normalize": bool, "overwrite": bool}` → `{"path"}`; 409 `{"exists": true, "path"}`; 400 `{"error"}` on `DraftError` |

Path rule for every `path` param: must be an entry in the index (lookup dict), else 404; additionally `(cfg.library / path).resolve()` must be inside `cfg.library.resolve()`, else 403. Check 403 first.
